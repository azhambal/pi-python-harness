Behavior now follows pi v1.4.0, checked against fixtures produced by pi's own code
(`tests/parity`, regenerated by `scripts/pi_reference/generate.sh`).

- Tool declarations, argument conversion and validation errors match pi; malformed
  tool-call JSON becomes a retryable tool error.
- `read` returns images (Photon WASM via Wasmtime); `write`/`edit` are pi's in-place writes with the
  per-file mutation queue, fuzzy matching and legacy argument shapes; edit
  `details` are pi's `diff`, `patch`, `firstChangedLine`.
- `bash`: `PI_*` session variables and prompt hint, pi's shell lookup, timeout and
  abort text, `pi-bash-*.log` full output kept after close.
- `grep`/`find`/`ls` are translations of pi's tools: `rg --json`, `fd --glob`
  (new requirement), Node `localeCompare` order for `ls`, pi's text and notices.
  Structured `items` and the 30-second search timeout are gone.
- Tool batches follow pi: parallel by default, no `max_parallel_tools`,
  `Tool.execution_mode` instead of `parallel_safe`, hook exceptions become error
  results, the hook context excludes results of the current batch.
- The system prompt matches pi's sections and order (without pi's `<docs>`);
  context files include `AGENTS.override.md`, `AGENTS.MD`, `CLAUDE.md`, `CLAUDE.MD`.
- The provider history follows pi's `transformMessages`; unanswered tool calls
  are answered with `"No result provided"` per request instead of recorded
  interruption results.
- Anthropic and OpenAI-compatible adapters are translations of pi's
  `anthropic-messages` and `openai-completions`, compared with pi's real request
  bodies and stream results. pi's model catalog (Anthropic, DeepSeek) ships with
  the package and supplies limits, prices and `compat` flags.
- Thinking levels follow pi: `thinking_level_map` uses pi's meaning and unsupported
  levels are clamped instead of rejected; Anthropic picks adaptive or budget
  thinking by model (`ANTHROPIC_THINKING_MODE` now only overrides).
- Context estimates and output caps follow pi (`estimateContextTokens`, 4096
  safety tokens). Malformed tool-call JSON is repaired or reported with V8's
  `JSON.parse` message.
- Compaction is a translation of pi's `prepareCompaction`/`compact`: chars/4 cut
  estimate, pi's split-turn rule and turn-prefix prompt, JavaScript-exact
  serialization, and summary requests with the session thinking level, no cache
  writes, no `max_tokens` and a fresh session ID. Simple exchanges are no longer
  kept whole, and empty summaries are accepted as in pi.
- Automatic compaction triggers follow pi: checks after each run, before each
  prompt and between turns (no longer before every request); length stops below
  the model limit and silent overflows are recovered; overflows from another
  model are ignored; a model switch no longer invalidates usage; nothing to
  compact is silent; `CompactionEnd.will_retry`. Overflow and retry patterns are
  pi's (usage alone no longer marks an error as overflow; HTTP 413 is overflow).
- `thinking_budgets` setting (pi's `thinkingBudgets`) for budget-based thinking
  on Anthropic and OpenAI-compatible providers.
- Drop cross-model thinking from provider requests and thinking from summary input.
- Retry transient summary failures.
- Bound provider output by model limits and estimated remaining context.
- Handle additional transient gateway errors and whitespace-only OpenAI tool results.
- Accept UTF-8 BOM and editor schema references in settings and MCP configuration.
- Ship settings/MCP schemas and a generated configuration field reference.
- Add relative CLI builtin selection and persisted native thinking-level maps.
- Upgrade the optional MCP SDK to 2.3.0 and Git/Fetch reference servers to 2026.10.19.
- Match Pi v1.4 MCP result envelopes, arbitrary structured JSON and explicit null.
- Preserve full structured results while spilling long model-facing text to owned temporary files.
- Reorganize documentation into focused public guides.
- Add SGLang request settings, thinking controls and reasoning-token accounting.

## 0.1.0 — initial repository snapshot, 2026-10-14

Initial release of the Python coding-agent harness. It is an alpha package, not a full Pi feature-parity release.

- Async provider-independent agent loop; DeepSeek/OpenAI-compatible and Anthropic adapters.
- Coding tools, bounded repository search, fuzzy edit and atomic file mutations.
- Durable linear sessions, resume, compaction, model switching, retries and cancellation.
- Tool hooks, allow/ask/deny policies, bounded parallel execution and live run/chat CLI.
- Compatible Agent Skills discovery, explicit invocation and durable resource snapshots.
- Optional bounded MCP stdio/Streamable HTTP, direct tools/text resources,
  strict binding restore, staged reload, explicit reconnect and owned cleanup.
- Pinned Git/Fetch examples and reproducible combined offline acceptance.
- User guides, contributor documentation and implementation contracts.

The package implements a text-first subset of Pi; see
[compatibility and scope](docs/compatibility.md).
